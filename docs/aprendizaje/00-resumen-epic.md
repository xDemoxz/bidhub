# Resumen de la epic: BidHub

Plataforma de subastas construida en modo **efectivo** para servir de base
a la prueba de desempeño. Cada feature tiene su nota.

| Nota | Feature |
|---|---|
| [01](01-modelo-de-datos.md) | Modelo de datos, migración y seed |
| [02](02-reglas-de-negocio.md) | Reglas de negocio y concurrencia |
| [03](03-autenticacion.md) | Autenticación JWT con cookies |
| [04](04-api-y-proxy.md) | API REST, errores y proxy |
| [05](05-interfaz-e18n.md) | Interfaz, rutas por grupo e i18n |
| [06](06-empaquetado.md) | Docker |

Cómo adaptar la base a una lógica nueva: [adaptacion.md](../adaptacion.md).
